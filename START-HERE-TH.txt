Document Scanner 1.0.3 — รุ่นสำหรับทดสอบบน Windows

1. Windows 64-bit: ใช้ ZIP win-x64 เป็นตัวเลือกแรก
2. Windows 10 32-bit: ใช้ ZIP win-x86
3. คลิกขวา ZIP > Extract All แล้วเปิด DocumentScanner.exe
4. ต้องเก็บ DLL, NAPS2.Worker.exe และโฟลเดอร์ประกอบไว้ด้วยกัน
5. ติดตั้งไดรเวอร์สแกนของผู้ผลิตก่อนสำหรับ WIA/TWAIN
6. เลือกเครื่องสแกน > Scan; เพิ่มหน้าใช้ Scan More
7. เลือกภาพย่อเพื่อหมุน ลบ เรียงหน้า หรือ Undo
8. Save เลือก JPG / PNG / PDF และโฟลเดอร์ปลายทาง

โปรแกรมมี Runtime ในตัว ไม่ต้องติดตั้ง .NET เพิ่มสำหรับแอปหลัก
เอกสารสแกนเก็บไว้ในเครื่อง ไม่มีการอัปโหลดอัตโนมัติ
ตอนปิดโปรแกรมเลือก Yes เพื่อเก็บ Session ไว้กู้คืน หรือ No เพื่อลบทิ้ง

สถานะการตรวจสอบ: Build และ Publish สำเร็จ ทั้งสองสถาปัตยกรรม
ดูผล Unit Tests และข้อจำกัดล่าสุดใน Validation-Report.txt
ยังไม่ผ่านการเปิดหน้าจอและการสแกนจริงบน Windows
หากเกิดปัญหาให้เก็บไฟล์ Logs และระบุรุ่น Scanner/Driver/Windows ที่ใช้

แก้ไข Auto Crop ในรุ่น 1.0.1:
- เลือกภาพย่อ แล้วกด Auto Crop เพื่อครอปหน้าที่เลือกทันที
- ใช้ Reset crop เพื่อคืนภาพเต็ม หรือ Undo เพื่อย้อนกลับ
- ภาพย่อและ Preview จะแสดงผล Crop พร้อมขนาดพิกเซลใต้ภาพ
- Checkbox Auto crop มีผลต่อหน้าที่เลือกและการสแกนครั้งถัดไป
- ถ้าส่งออก PDF แบบ A4/Letter ขนาดกระดาษยังเป็น A4/Letter ให้เลือก Original หากต้องการขนาด PDF ตามภาพที่ครอป

แก้ Save/Load Profile ในรุ่น 1.0.2:
1. ปิดโปรแกรมก่อนอัปเดต และเก็บโฟลเดอร์ Config เดิมไว้
2. เลือก Scanner และตั้ง Paper Source / DPI / Color Mode / Paper Size
3. ใส่ชื่อ Profile แล้วกด Save profile
4. เปลี่ยนค่าในหน้าจอ จากนั้นเลือก Profile แล้วกด Load profile เพื่อตรวจสอบ
5. หาก Scanner ไม่รองรับค่าที่บันทึกไว้ โปรแกรมจะแสดงคำเตือน
Profile ที่รุ่นเก่าเคยบันทึกค่าเริ่มต้นผิดไปแล้ว ต้องตั้งค่าที่ต้องการและ Save ใหม่

แก้ไขโทนภาพในรุ่น 1.0.3:
- แสดงค่า Brightness และ Contrast เป็นตัวเลขจริงข้าง Slider
- มีปุ่ม Reset Brightness / Contrast to 0
- ค่า 0 คือไม่ปรับโทนภาพเพิ่มเติมด้วยโปรแกรม
- ค่าด้านขวาใช้กับการสแกนครั้งใหม่; ใต้ Preview แสดง B/C ของหน้าที่เลือก
- Auto Crop ตัดขอบเท่านั้น ไม่เปลี่ยนค่าปรับโทนและไม่เขียนทับต้นฉบับ
- หลังอัปเดตให้กด Reset to 0 แล้วลองสแกนใหม่
- ถ้าเปิดหน้าตั้งค่าของ Scanner เอง ให้รีเซ็ตโทนในหน้าต่างนั้นด้วยเมื่อต้องการเปรียบเทียบ

รุ่น 1.0.4 — Manual Crop / Auto Color
- เลือก 1 หน้า กด Manual Crop แล้วลากกรอบส่วนที่ต้องการเก็บ กด Apply Crop เพื่อยืนยัน หรือ Cancel/Escape เพื่อยกเลิก ลากกรอบใหม่เพื่อเปลี่ยนได้ หากปรับขนาดหน้าต่างต้องเลือกกรอบใหม่
- Manual Crop แสดงภาพเต็มตามทิศที่หมุนไว้ ทำให้เลือกขอบที่เคยตัดออกกลับมาได้ ใช้ Reset crop เพื่อคืนเต็มหน้า หรือ Undo เพื่อย้อนการแก้ไข
- เลือกหนึ่งหรือหลายหน้า กด Auto Color เพื่อปรับสีพื้นกระดาษและความชัด ใช้ Reset Auto Color เพื่อปิด โดยคง Brightness/Contrast เดิม
- ไม่เขียนทับภาพต้นฉบับ การกด Auto Color ซ้ำไม่สะสมการปรับสี และบันทึกผลเหมือน Preview
- เหมาะกับเอกสาร ควรตรวจภาพถ่ายและกระดาษสีก่อนบันทึก ระบบไม่ได้คืนรายละเอียดที่หายไปแล้ว

รุ่น 1.1.0 — UI ใหม่, Profiles และ ERPNext (Validation Candidate)
- เลือก Profile บน toolbar หรือเปิด Manage profiles เพื่อสร้าง/Save/Save As/Rename/Delete/ตั้ง Default/Import/Export JSON
- Profile เก็บ Scanner/Processing/Output/ERPNext ครบ กลไกโหลดตรวจความสามารถก่อนใช้ ไม่มีการแทน DPI/Source/Color ที่ไม่รองรับโดยเงียบ ๆ
- Advanced scan defaults ใช้กับหน้าใหม่ ส่วน Selected pages ใช้แก้ภาพที่เลือกและต้องกด Apply tone
- Save Local / Send to ERPNext / Save Local & Send to ERPNext ทำงานกับหน้าที่เลือกเท่านั้น
- ส่ง ERPNext ต้องติดตั้ง document_scanner_bridge ฝั่งเซิร์ฟเวอร์ก่อน ดู ERPNext-Setup.md ใน source หรือแพ็กเกจ Bridge จาก GitHub Actions
- ตั้ง Site/API credentials ผ่าน Manage profiles → ERPNext → Manage sites ไม่เก็บ secret ใน Profile JSON
- ค้นหาเอกสาร ดูรายละเอียดจริง กด Confirm destination แล้วกด Send now แยกอีกครั้ง
- ผลลัพธ์ Local/ERPNext แยกกัน Retry ตรวจ server receipts ก่อนส่งซ้ำ ไม่ส่งไฟล์ที่ยืนยันสำเร็จแล้ว
- New document เริ่ม session ใหม่ ส่วน Scan more เพิ่มหน้าในเอกสารเดิม
- ยังต้องทดสอบกับเครื่องสแกนจริงและ ERPNext staging ของผู้ใช้ก่อนใช้งานจริง ไม่ได้ deploy หรือทดสอบไซต์จริงในขั้นตอน build นี้

รุ่น 1.1.1 — ปรับ Initial ตาม Profile
- ยังไม่มี Profile: ค้นหาเครื่องทุกระบบตามเดิม
- มี Default Profile: ตรวจเครื่องและ Driver นั้นก่อน แล้วอ่าน Capabilities ครั้งเดียวในขั้นตอนโหลด
- มี Profile แต่ยังไม่มี Default หรือ Default อ้างอิงรายการที่ไม่มีแล้ว: รอให้เลือก Profile หรือกด Reset Profile
- Load Profile: ค้นหาเฉพาะเครื่อง/Driver ที่บันทึกไว้ แม้ยังไม่เคยค้นพบในรอบเปิดโปรแกรมนี้
- Reset Profile / F5: ยกเลิก Profile ที่กำลังใช้และค้นหาใหม่ทั้งหมด ไม่ลบ Profile ที่บันทึก ไม่ยกเลิก Default ที่บันทึกไว้ และไม่ลบภาพ/session/งานส่งค้าง
- เครื่องของ Profile ไม่พร้อม: แจ้งข้อผิดพลาด ไม่เปลี่ยนเครื่องหรือค้นหาทุกระบบเองโดยอัตโนมัติ
- Logs เพิ่มเวลาของแต่ละขั้นตอนเพื่อเทียบกับเครื่องจริง ยังไม่อ้างอิงตัวเลขว่าทำงานเร็วขึ้นกี่วินาที
